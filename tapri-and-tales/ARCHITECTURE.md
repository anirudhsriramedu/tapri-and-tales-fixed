# Architecture
The browser entrypoint `index.html` loads `src/main.js`, which renders semantic HTML and wires DOM controls. Game rules and calculations live in isolated pure functions in `src/engine.js`. The state is saved to localStorage on every transition. `server.mjs` is a static Node HTTP server for local development and makes no network requests. Cash, sales and COGS are integer paise. Stock units are millilitres, grams or pieces. Each stock item stores quantity and weighted-average paise/unit. Sales append immutable day-tagged ledger entries. `report()` aggregates the event ledger. `quickDay()` uses a seeded PRNG and the same `serve()` operation as manual play. Shock modifies new milk supplier prices without changing existing stock basis.
