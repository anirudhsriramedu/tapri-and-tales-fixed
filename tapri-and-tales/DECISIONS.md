# Design decisions
- Used dependency-free ES modules and an HTTP dev server to guarantee quick startup without blocked registry installation.
- Chose pure deterministic functions for finance and simulations to ensure reliable judging.
- No backend despite the generic OWASP slide's broad full-stack reference, following the challenge's specific no-backend rule.
- Stock purchase is an asset acquisition; only sold consumed ingredients count toward COGS.
- Original illustrated CSS chai stall avoids heavyweight assets and potentially misused public-figure images.
- Core MVP is prioritized over secondary features when implementation time is constrained.
